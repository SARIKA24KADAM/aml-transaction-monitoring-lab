# Role capability alignment

| Capability | Project artifact |
|---|---|
| Analyze large datasets with Python and SQL | DuckDB-backed feature preparation, pandas analysis, Parquet outputs |
| Build and tune transaction monitoring | Configurable transparent behavioral rules and threshold comparisons |
| Supervised and unsupervised learning | Logistic regression and Isolation Forest comparison |
| Network analysis | Directed account-flow graph, degrees, flow amounts, components, PageRank |
| Visualize model performance | Interactive Streamlit/Plotly trend, segment, alert-rate, recall, and amount graphs |
| Data requirements subject-matter work | Data dictionary and schema checks |
| Communicate to leaders and reviewers | Model white paper, assumptions, definitions, and limitations |
| Independent review readiness | Reproducibility notes, leakage controls, version/validation recommendations |

This project demonstrates a learning workflow using synthetic data; it does not claim production AML experience or compliance expertise.
